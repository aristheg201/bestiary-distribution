BESTIARY REBIRTH · JAVA EDITION

A focused launcher for the Bestiary community.

Bestiary Launcher installs and updates the server client, manages optional client content, and supports a separate server-local/offline identity mode alongside Microsoft-authenticated Minecraft: Java Edition accounts.

01

Managed client

Downloads the exact Bestiary release selected by the server distribution, including pinned Minecraft, Fabric Loader and Java runtime requirements.

02

Content management

Provides a dedicated screen for mods, resource packs and shaders, including drag-and-drop installation of personal client content.

03

Account choice

Players may use the community's server-local/offline identity mode or explicitly sign in with a Microsoft account that owns Minecraft: Java Edition. The two authentication paths are separate.

MICROSOFT AUTHENTICATION

No Microsoft password is collected by the launcher.

Bestiary Launcher uses Microsoft's Device Code Flow as a native/public client. The player completes sign-in on Microsoft's own website. The launcher then exchanges the resulting Microsoft token through Xbox Live, XSTS and Minecraft Services to verify Java Edition ownership and retrieve the player's Minecraft profile. Server-local/offline mode does not use this token or call the Java Edition entitlement/profile APIs.

PRIVACY

Local-first account storage

Refresh credentials are stored locally using the operating-system-backed secure storage available to the desktop application. Access tokens are not exposed to the launcher renderer UI.
